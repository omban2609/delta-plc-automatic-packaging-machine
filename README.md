# Automatic Packaging Machine

Industrial packaging machine simulation developed using Delta PLC and Delta HMI software.

## Overview

This project simulates an industrial automatic packaging machine using Delta ISPSoft and DOPSoft.

The machine detects incoming products on a conveyor, stops at the correct position, actuates a pneumatic pusher cylinder, and resumes conveyor operation after packaging.

The project is completely software simulated and requires no physical PLC hardware.

---

## Machine Sequence

1. Operator presses Start
2. Conveyor begins moving
3. Product reaches sensor
4. Conveyor stops
5. Pneumatic cylinder extends
6. Product is pushed into the box
7. Cylinder retracts
8. Conveyor restarts
